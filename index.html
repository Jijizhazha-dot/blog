关于这个博客

这个站点是纯静态的：index.html 负责首页，article.html 负责正文，文章本身是 posts/ 目录里一个个 Markdown 文件，托管在 GitHub Pages 上。

加一篇文章只需要往 posts/ 里上传一个 .md 文件：标题、日期、标签写在文件开头的 front matter 里，首页、归档、分类、标签都会自动更新。
