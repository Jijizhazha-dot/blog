# Vim 常用命令：从第一次编辑到日常速查

![Vim 教程封面（AI 生成插画）](images/2026-10-21-vim-guide-02.jpg)

Vim 是一种支持模式化编辑的文本编辑器。它可以在终端中运行，常用于修改配置、编辑代码和查看文本。

学习时，先掌握输入、保存、退出与撤销，再逐步增加移动和组合命令，不必一次记住全部按键。

本文以未安装额外插件的 Vim 为基础。不同系统、版本和配置可能影响部分行为；示例未实机测试。

## 一、先看懂操作说明

本文使用三种操作位置：

| 操作位置 | 示例 | 如何执行 |
|---|---|---|
| 操作系统终端 | `vim vim-demo.txt` | 启动 Vim 之前，在终端输入并回车 |
| Vim 普通模式 | `gg`、`dd`、`ciw` | 先按 `Esc`，再依次按键，不用回车 |
| Vim 命令行 | `:w`、`:q` | 普通模式按 `:`，输入后按 Enter |

搜索 `/word`、`?word` 也从普通模式开始，输入后按 Enter。

按键记法：

- `Esc`：按键盘上的 Esc，不是输入三个字母。
- `Ctrl+r`：按住 Ctrl，再按 r。
- `gg`：连续按两次小写 g。
- `10G`：依次按 1、0、Shift+g。
- `Ctrl+w` → `w`：先按 Ctrl+w，松开后再按 w。
- 大小写不同的命令通常有不同作用，例如 `i` 和 `I`。

不确定当前模式时，通常可以先按 `Esc`，再执行普通模式命令。

## 二、安装与启动

只选择适合当前系统的一种安装方式。

### Debian / Ubuntu

在终端执行：

```bash
sudo apt update
sudo apt install vim
```

### Fedora / 使用 DNF 的系统

```bash
sudo dnf install vim
```

部分旧系统使用 YUM：

```bash
sudo yum install vim
```

### macOS

安装 Homebrew 后，可执行：

```bash
brew install vim
```

### Windows

可以使用官方安装程序，或通过 winget 安装：

```powershell
winget install --id vim.vim --exact
```

安装完成后，可能需要重新打开终端。

### 验证与交互教程

```bash
vim --version
```

在终端启动自带教程：

```bash
vimtutor
```

部分安装方式可能未提供 `vimtutor` 启动程序。

在 Vim 内查看帮助：

```vim
:help
```

查看具体主题：

```vim
:help motion
```

帮助通常在单独窗口打开，可以用 `:q` 关闭该帮助窗口。

## 三、第一次完整编辑

先在终端切换到自己的练习目录，确认没有需要保留的同名文件。

### 1. 打开文件

在终端执行：

```bash
vim vim-demo.txt
```

文件不存在时，Vim 会打开一个新的缓冲区；成功保存后，才会创建磁盘文件。

### 2. 输入三行文本

按小写 `i` 进入插入模式，再输入：

```text
Hello Vim
old value
ERROR sample
```

每行之间按 Enter 换行。

输入完成后按 `Esc`，回到普通模式。

### 3. 保存

输入以下命令并按 Enter：

```vim
:w
```

成功后会显示写入信息，文件仍保持打开。

### 4. 搜索并修改一个单词

先按 `gg` 回到文件开头，再输入：

```text
/old
```

按 Enter，光标会定位到匹配位置。

普通模式按 `ciw`，输入 `new`，再按 `Esc`。

第二行应变成：

```text
new value
```

### 5. 撤销与重做

普通模式按 `u`，撤销刚才的修改。

再按 `Ctrl+r`，恢复修改。

### 6. 保存并退出

```vim
:wq
```

只有一个编辑窗口时，这通常会回到终端。

之后可以重新打开文件，检查保存结果：

```bash
vim vim-demo.txt
```

后文涉及该文件的练习，以重新打开后的内容为基础。不同示例按需操作，不必连续执行。

## 四、常用模式

| 模式 | 用途 | 常用进入方式 | 常用离开方式 |
|---|---|---|---|
| 普通模式 | 移动、删除、复制、执行编辑动作 | 默认启动状态；其他模式按 Esc | 按 `i`、`v`、`:` 等 |
| 插入模式 | 输入文本 | `i`、`a`、`o` | Esc |
| 命令行模式 | 保存、替换、设置等 | `:`；搜索使用 `/` 或 `?` | Enter 执行；Esc 取消 |
| 可视模式 | 选择文本后操作 | `v`、`V`、`Ctrl+v` | Esc |
| 替换模式 | 连续覆盖已有字符 | `R` | Esc |

初学阶段可以采用固定步骤：先按 Esc 回到普通模式，再开始下一项操作。

终端对 `Ctrl+v` 的处理可能不同；若它被用于粘贴，可尝试 `Ctrl+q` 进入可视块模式，具体取决于环境。

## 五、打开文件与定位

以下命令在操作系统终端执行。

打开文件：

```bash
vim vim-demo.txt
```

打开并定位到第 5 行：

```bash
vim +5 vim-demo.txt
```

打开并定位到最后一行：

```bash
vim + vim-demo.txt
```

打开并搜索第一个 `ERROR`：

```bash
vim +/ERROR vim-demo.txt
```

不要使用 `vim file.txt /word` 搜索；它通常会把 `/word` 当作另一个文件参数。

实际定位位置还可能受文件内容和 Vim 配置影响。

## 六、移动光标

以下均在普通模式执行。

| 范围 | 按键 | 作用 |
|---|---|---|
| 字符 | `h`、`j`、`k`、`l` | 左、下、上、右 |
| 单词 | `w` | 下一个单词的开头 |
| 单词 | `b` | 向前移动到单词开头 |
| 单词 | `e` | 单词末尾 |
| 行内 | `0` | 绝对行首 |
| 行内 | `^` | 当前行首个非空白字符 |
| 行内 | `$` | 行尾 |
| 文件 | `gg` | 第一行 |
| 文件 | `G` | 最后一行 |
| 文件 | `10G` | 第 10 行 |
| 屏幕 | `H`、`M`、`L` | 屏幕顶部、中部、底部附近的行 |
| 翻页 | `Ctrl+f`、`Ctrl+b` | 向下、向上翻页 |
| 视图 | `zz` | 将光标所在行移到窗口中部 |
| 匹配 | `%` | 在匹配的括号之间跳转 |

方向键通常也可使用。

### 次数与动作组合

数字通常表示次数：

```text
5j
```

表示向下移动 5 行。

```text
3w
```

表示向前移动 3 个单词。

### 行内查找

依次按 `f` 和目标字符，会向右定位到当前行下一个该字符。

例如：

```text
f,
```

表示查找当前行后面的逗号。

`F` 向左查找；`;` 重复最近的行内查找，`,` 反向重复。

## 七、输入、修改与删除

### 进入插入模式

| 按键 | 作用 |
|---|---|
| `i` | 在光标前插入 |
| `a` | 在光标后插入 |
| `I` | 在当前行首个非空白字符前插入 |
| `A` | 在当前行末尾插入 |
| `o` | 在下方新建一行并插入 |
| `O` | 在上方新建一行并插入 |

如果要在绝对行首插入，可以依次按 `0i`。

### 修改文本

| 按键 | 作用 |
|---|---|
| `r` 后接一个字符 | 替换光标处的一个字符 |
| `ciw` | 删除当前完整单词并进入插入模式 |
| `cw` | 从当前位置按单词动作规则修改文本 |
| `cc` | 修改当前整行，通常保留适用的缩进 |
| `C` | 从当前位置修改到行尾 |
| `.` | 重复最近一次可重复的修改 |

`ciw` 更适合"光标位于单词中间，仍要修改整个单词"的场景。

### 删除文本

| 按键 | 作用 |
|---|---|
| `x` | 删除光标处字符 |
| `X` | 删除光标前字符 |
| `dd` | 删除当前行 |
| `3dd` | 从当前行开始删除 3 行 |
| `diw` | 删除当前完整单词 |
| `dw` | 从当前位置删除到下一单词边界，范围受动作规则影响 |
| `d$` 或 `D` | 删除到行尾 |
| `d0` | 删除到行首之前 |

普通删除通常会把文本写入寄存器，可以再用 `p` 或 `P` 放回。

## 八、复制、粘贴与可视选择

### 复制与粘贴

| 按键 | 作用 |
|---|---|
| `yy` | 复制当前行 |
| `3yy` | 从当前行开始复制 3 行 |
| `yiw` | 复制当前完整单词 |
| `y$` | 复制到行尾 |
| `p` | 放到光标后；整行文本放到当前行下方 |
| `P` | 放到光标前；整行文本放到当前行上方 |

### 选择后操作

1. 按 `v` 进入字符可视模式，或按 `V` 进入整行可视模式。
2. 移动光标扩大选择。
3. 按 `y` 复制，或按 `d` 删除。
4. 移动到目标位置，按 `p` 粘贴。

### 命名寄存器

依次按以下按键，将当前行复制到寄存器 a：

```text
"ayy
```

读取寄存器 a：

```text
"ap
```

开头的 `"` 是实际需要按下的字符。

查看寄存器内容：

```vim
:registers
```

常用寄存器：

- 未命名寄存器：普通复制、删除和粘贴经常使用的默认位置。
- `"0`：通常保留最近一次未显式指定其他寄存器的复制内容。
- `"1`～`"9`：保存部分删除或修改历史，不是所有删除的统一记录。
- `"a`～`"z`：可主动使用的命名寄存器。

如果复制后又删除了其他内容，可尝试用 `"0p` 粘贴之前复制的内容。

### 系统剪贴板

在支持系统剪贴板的环境中：

```text
"+yy
```

复制当前行到系统剪贴板。

```text
"+p
```

从系统剪贴板粘贴。

`"+` 和 `"*` 的具体行为取决于操作系统、图形会话及 Vim 构建。远程 SSH 中也不保证能直接访问本机剪贴板。

检查相关帮助：

```vim
:help clipboard
```

## 九、撤销与重做

普通模式：

| 按键 | 作用 |
|---|---|
| `u` | 撤销一次修改 |
| `Ctrl+r` | 重做 |
| `U` | 撤销最近修改行上的一组修改，行为不同于普通撤销 |

日常优先掌握 `u` 与 `Ctrl+r`。

误删后先按 Esc，再按 `u`，通常比立即退出更容易检查和恢复当前编辑。

## 十、搜索与替换

### 搜索

从普通模式输入并回车：

```text
/ERROR
```

向文件后方搜索。

```text
?ERROR
```

向文件前方搜索。

后续按键：

- `n`：沿最近搜索方向继续。
- `N`：沿最近搜索的反方向继续。
- `*`：搜索光标所在的单词。

默认搜索可能到文件尾后绕回开头，取决于 `wrapscan` 设置。

开启匹配高亮：

```vim
:set hlsearch
```

临时清除当前高亮：

```vim
:nohlsearch
```

后续搜索可能重新显示高亮。

### 替换

当前行只替换第一个匹配：

```vim
:s/old/new/
```

当前行替换所有匹配：

```vim
:s/old/new/g
```

第 10～20 行替换：

```vim
:10,20s/old/new/g
```

全文替换：

```vim
:%s/old/new/g
```

全文替换并逐个确认，适合第一次尝试：

```vim
:%s/old/new/gc
```

常用确认按键：

| 按键 | 作用 |
|---|---|
| `y` | 替换当前匹配 |
| `n` | 跳过当前匹配 |
| `a` | 替换剩余全部匹配 |
| `q` | 停止替换 |

只匹配完整单词：

```vim
:%s/\<old\>/new/gc
```

搜索部分默认使用模式匹配；`.`、`*` 等可能具有特殊含义。替换部分中的 `&` 等字符也有特殊含义，处理路径或复杂文本时应先查帮助：

```vim
:help :substitute
```

## 十一、保存、退出与其他文件

### 保存和退出

| 命令 | 作用 |
|---|---|
| `:w` | 保存当前文件 |
| `:q` | 关闭当前窗口；未保存修改可能阻止退出 |
| `:wq` | 保存并关闭当前窗口 |
| `:q!` | 强制关闭当前窗口；可能丢弃未保存修改 |
| `:qa` | 尝试关闭所有窗口并退出 |
| `:qa!` | 强制全部退出，丢弃未保存修改 |
| `:wqa` | 写入已修改的缓冲区并尝试全部退出 |

只有一个窗口时，关闭该窗口通常会退出 Vim。

如果同一缓冲区仍在其他窗口显示，关闭一个窗口不一定丢弃它的修改。

普通模式的 `ZZ` 也可以在需要时保存并关闭当前窗口。

### 强制保存不等于获得权限

```vim
:w!
```

该命令可覆盖部分 Vim 层面的限制，但不会授予操作系统权限，也不能保证突破文件权限、只读文件系统或目录限制。

保存失败时，先检查错误信息；必要时写入自己有权限的位置。

### 写副本与另存为

写一份副本：

```vim
:w copy.txt
```

当前缓冲区通常仍关联原来的文件名。

保存为新文件，并把当前缓冲区切换到新文件名：

```vim
:saveas renamed.txt
```

这些命令通常会阻止意外覆盖已有文件，除非显式使用相应强制形式。

### 读取其他文件内容

将 `other.txt` 的内容插入当前行之后：

```vim
:read other.txt
```

插入第 5 行之后：

```vim
:5read other.txt
```

打开另一个文件：

```vim
:edit other.txt
```

当前内容未保存时，Vim 可能阻止切换；应先决定保存还是放弃修改。

## 十二、行号、编码与换行格式

### 显示行号

```vim
:set number
```

关闭：

```vim
:set nonumber
```

### 查看当前设置

```vim
:set encoding? fileencoding? fileformat?
```

- `encoding`：Vim 内部处理文本的编码。
- `fileencoding`：当前缓冲区保存到文件时使用的编码。
- `fileformat`：文件换行格式。

### 按 UTF-8 保存

```vim
:set fileencoding=utf-8
```

再执行 `:w` 才会写入文件。

如果文件已经因错误解码而显示乱码，直接修改保存编码不一定能修复内容。

### 按指定编码重新读取

确认当前没有需要保留的未保存修改后，可使用：

```vim
:edit ++enc=utf-8
```

这会重新读取当前文件。应根据文件真实编码选择参数。

### 修改换行格式

Unix 风格 LF：

```vim
:set fileformat=unix
```

Windows 风格 CRLF：

```vim
:set fileformat=dos
```

设置后保存生效。换行格式与字符编码是两个不同问题。

## 十三、分屏与窗口

在 Vim 命令行执行：

水平分屏：

```vim
:split
```

垂直分屏：

```vim
:vsplit
```

分屏打开其他文件：

```vim
:vsplit other.txt
```

普通模式中的窗口按键：

| 按键 | 作用 |
|---|---|
| `Ctrl+w` → `w` | 切换到下一个窗口 |
| `Ctrl+w` → `h` | 切换到左侧窗口 |
| `Ctrl+w` → `j` | 切换到下方窗口 |
| `Ctrl+w` → `k` | 切换到上方窗口 |
| `Ctrl+w` → `l` | 切换到右侧窗口 |
| `Ctrl+w` → `q` | 关闭当前窗口 |
| `Ctrl+w` → `o` | 只保留当前窗口，未保存状态可能阻止操作 |

窗口是显示区域，缓冲区是编辑中的文本。同一个文件可以同时显示在多个窗口中。

## 十四、自动缩进

普通模式依次按：

```text
gg=G
```

表示从文件首行开始，对全文执行自动缩进。

对第 10～20 行执行自动缩进：

```text
10G11==
```

含义是先跳到第 10 行，再对包含当前行在内的 11 行执行缩进。

也可以按 `V` 选择多行，再按 `=`。

结果依赖文件类型、缩进设置或相关插件。自动缩进主要调整缩进，不等于完整的代码格式化。

## 十五、基础配置

Linux 和 macOS 常用用户配置文件是 `~/.vimrc`；Windows 常见配置文件是 `$HOME/_vimrc`，也可能使用其他位置。

查看配置文件位置与读取顺序：

```vim
:help vimrc
```

系统配置路径随安装方式变化，不建议照抄固定系统路径。

下面是一份不依赖插件的基础配置。将其合并到自己的 Vim 配置文件中，不要直接覆盖已有配置。

```vim
" Show line numbers.
set number
" Display a tab character using four columns.
set tabstop=4
" Use four columns for each indentation level.
set shiftwidth=4
" Insert spaces when pressing Tab.
set expandtab
" Preserve indentation when starting a new line.
set autoindent
" Highlight search matches.
set hlsearch
set incsearch
" Enable syntax highlighting and filetype support.
syntax on
filetype plugin indent on
```

`expandtab` 不会自动把已有 Tab 全部转换为空格。

基础配置不加入"一键运行当前 Python 文件"等映射，因为解释器名称、文件路径、Shell 和工作目录都可能影响运行结果。

## 十六、进阶入口

### 原生包机制与插件

Vim 支持原生包目录机制。第三方插件管理器则提供额外的下载、更新和声明方式。

例如，`:PlugInstall` 是安装并配置 vim-plug 后才提供的命令，不是 Vim 自带命令。

学习插件前，建议先掌握：

- 移动与次数；
- `d`、`c`、`y` 与动作的组合；
- 搜索和替换；
- 可视选择；
- 寄存器与窗口。

### 远程文件

部分环境可以通过 netrw 编辑远程文件：

```bash
vim scp://user@host//path/to/file
```

使用前需替换账户、主机和路径，并满足 netrw、SSH 工具、认证、网络与文件权限等条件。

更简单的方式是先通过 SSH 登录远程主机，再运行远程 Vim。

### Neovim

Neovim 是从 Vim 发展而来的编辑器，具有独立的配置方式和插件生态，支持 Lua 配置和内置 LSP 客户端等功能。

本文的基础操作大多适用，但配置文件和插件安装方法不能直接混用。

## 十七、命令速查

以下按键默认从普通模式开始；冒号命令和搜索输入后需要按 Enter。

| 场景 | 命令或按键 |
|---|---|
| 回到普通模式 | Esc |
| 开始输入 | `i` |
| 下方新增一行 | `o` |
| 文件开头、结尾 | `gg`、`G` |
| 行首、行尾 | `0`、`$` |
| 修改完整单词 | `ciw` |
| 删除、复制当前行 | `dd`、`yy` |
| 粘贴 | `p`、`P` |
| 撤销、重做 | `u`、Ctrl+r |
| 重复最近修改 | `.` |
| 搜索 | `/word` |
| 继续、反向搜索 | `n`、`N` |
| 全文替换并确认 | `:%s/old/new/gc` |
| 保存 | `:w` |
| 保存并关闭当前窗口 | `:wq` |
| 强制全部退出 | `:qa!` |
| 显示行号 | `:set number` |
| 垂直分屏 | `:vsplit` |
| 全文自动缩进 | `gg=G` |
| 查看帮助 | `:help` |
