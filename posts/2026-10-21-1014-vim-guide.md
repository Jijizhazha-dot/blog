## 一、什么是 Vim？

**Vim（Vi IMproved）** 是经典文本编辑器 **Vi** 的增强版本，也是 Linux/Unix 下最常见的文本编辑器之一。它从 vi 发展而来，代码补全、编译及错误跳转等面向编程的功能特别丰富，在程序员中被广泛使用。

Vim 的核心特点：

- **多模式编辑**：普通、插入、命令等模式各司其职；
- **全键盘化操作**：手不离键盘即可完成一切，效率极高；
- **支持插件扩展**：生态庞大，功能无限延伸；
- **支持语法高亮、自动缩进**：写代码体验友好。

一句话：vi 是老式字处理器，功能已经很齐全；Vim 则是程序开发者手中"终极利器"。

## 二、安装 Vim

```bash
# Debian / Ubuntu
sudo apt install vim
# CentOS / RHEL / Fedora
sudo yum install vim        # 或 dnf install vim
# macOS（Homebrew）
brew install vim
# Windows：官网下载安装包，或包管理器
winget install vim.vim
# 验证
vim --version
```

## 三、三大模式详解

Vim 的模式化设计是其灵魂。打开文件默认进入**普通模式**，输入 `i/a/o` 进入**插入模式**，按 `:` 进入**末行模式（命令行模式）**：

| 模式 | 作用 | 进入方式 | 退出方式 |
|---|---|---|---|
| 普通模式（Normal） | 浏览、删除、复制、粘贴 | 打开文件即是 | 按 `Esc` 返回 |
| 插入模式（Insert） | 输入文本 | 按 `i/a/o` 等 | 按 `Esc` |
| 末行模式（Command） | 保存、退出、查找、替换 | 按 `:` | 命令执行后自动返回 |

**切换关系**：插入模式和末行模式不能直接互切，都要先回到普通模式；普通模式是唯一"中转站"。此外还有**可视模式**（`v` 进入，用于选中文本）和**替换模式**（`R` 进入）。

## 四、打开文件的方式

```bash
vim file.txt        # 打开文件，光标在第一行行首（不存在则自动创建）
vim file.txt +5     # 光标位于第 5 行
vim file.txt +      # 光标位于末行行首
vim file.txt /word  # 光标直接跳到第一个匹配 word 的位置
```

## 五、光标移动命令（普通模式）

**字符级**：`h` 左 / `j` 下 / `k` 上 / `l` 右（方向键同样可用）

**单词级**：`w` 跳到下一个单词词首，`b` 回到上一个单词词首，`e` 跳到单词词尾

**行内**：`0` 跳到行首，`$` 跳到行尾，`^` 跳到行首第一个非空白字符

**行内查找**：`f` + 字符 → 向右跳到该字符；`F` + 字符 → 向左

**屏幕级**：`H` 屏幕顶部 / `M` 屏幕中部 / `L` 屏幕底部；`Ctrl+f` 向下翻页 / `Ctrl+b` 向上翻页；`zz` 将当前行居中

**文件级**：`gg` 跳到首行，`G` 跳到末行，`10G` 跳到第 10 行；`Ctrl+g` 显示当前行号与文件信息

**括号匹配**：`%` 在成对括号 `() [] {}` 间跳转

## 六、插入与编辑

```text
i    在光标前插入      a    在光标后插入
I    在行首插入        A    在行尾插入
o    在下方新建一行    O    在上方新建一行
s    删除光标字符并插入  S   删除整行并插入
cw   改写光标所在单词   cc   改写整行
```

常用技巧：`10iabc<Esc>` 可快速重复插入 10 次 "abc"；插入模式中 `Ctrl+w` 删除上一个词、`Ctrl+u` 删除到行首。

## 七、删除与剪切

```text
x    删除光标处字符       X    删除光标前字符
dd   删除整行（剪切）     3dd  删除光标起 3 行
dw   删除一个单词         d$  删除到行尾
d0   删除到行首           D   删除到行尾（同 d$）
```

删除的内容会被存入寄存器，相当于"剪切"，可用 `p` 粘贴到别处。

## 八、复制、粘贴与寄存器

```text
yy   复制当前行           y$   复制到行尾
yw   复制一个单词         3yy  复制 3 行
p    粘贴到光标之后        P    粘贴到光标之前
```

**寄存器**：`"a` 到 `"z` 共 26 个命名寄存器，可保存多段文本互不覆盖——`"ayy` 存入 a，`"ap` 取出。还有 10 个数字寄存器（`"0`~`"9`，自动记录最近删除）和只读寄存器（如 `"*` 系统剪贴板，`"+` 剪贴板寄存器：`"+yy` 复制、`"+p` 粘贴，可跨应用使用）。

## 九、撤销与重做

```text
u    撤销上一步         Ctrl+r  重做（撤销"撤销"）
U    撤销整行的所有修改
```

## 十、搜索与替换

**搜索**：普通模式按 `/` 输入关键词回车，`n` 下一个匹配、`N` 上一个匹配；`?word` 向上搜索；`:set hlsearch` 开启高亮、`:nohlsearch` 临时取消。

**替换**（末行模式，威力强大）：

```vim
:s/old/new          " 替换当前行第一个 old
:s/old/new/g        " 替换当前行所有 old
:10,20s/old/new/g   " 替换 10-20 行
:%s/old/new/g       " 全文替换
:%s/old/new/gc      " 全文替换，逐个确认（c=confirm）
:%s/\<word\>/new/g  " 精确匹配整个单词
```

## 十一、保存退出与文件操作（末行模式）

```vim
:w        保存文件
:q        退出
:wq       保存并退出（也可用 ZZ）
:w!       强制保存
:q!       强制退出不保存
:wq!      强制保存并退出
:w 1.txt  另存为 1.txt
:1,3 w 1.txt  将 1-3 行另存到 1.txt
:r 2.txt  将 2.txt 内容读入到光标所在行
:5 r 2.txt  读入到第 5 行之后
:e file   打开另一个文件
```

**文件编码与行号**：`:set nu` 显示行号、`:set nonu` 取消；`:set fenc=utf-8` 设置编码；`%s/换行符/新/g` 可做格式转换。

## 十二、多窗口与分屏

```vim
:sp file     水平分屏打开 file
:vsp file    垂直分屏打开 file
Ctrl+w w     在窗口间切换
Ctrl+w s     水平拆分          Ctrl+w v     垂直拆分
Ctrl+w q     关闭当前窗口      Ctrl+w o     只保留当前窗口
```

## 十三、配置 .vimrc

永久设置写入配置文件（`~/.vimrc` 仅影响当前用户，`/etc/vimrc` 影响所有用户）：

```vim
set nu              " 显示行号
set tabstop=4       " Tab 占 4 个空格
set shiftwidth=4    " 缩进 4 格
set expandtab       " Tab 转为空格
set hlsearch        " 搜索高亮
syntax on           " 语法高亮
set autoindent      " 自动缩进
" 常用映射：F5 一键运行当前 Python 文件
map <F5> :w<CR>:!python %<CR>
```

## 十四、插件与 NeoVim

- **Vim 8 原生包管理**：`packadd` + `~/.vim/pack/` 目录；
- **vim-plug**（推荐）：`~/.vimrc` 中声明后 `:PlugInstall` 一键安装；
- **经典插件**：`vim-surround`（快速加/改引号括号）、`vim-commentary`（`gc` 一键注释）、`vim-fugitive`（Git 集成）、`fzf.vim`（模糊查找文件）、`nerdtree`（文件树）；
- **NeoVim**：Vim 的现代化分支，内置 LSP、异步插件，配置用 Lua，适合想深入折腾的玩家。

## 十五、实战场景速写

- **编辑远程文件**：`vim scp://user@host//path/file`（需要 vim 编译支持）；
- **批量注释/取消注释**：`Ctrl+v` 进入可视块模式 → 选中列 → `I//<Esc>` 或 `d`；
- **代码格式化**：`:10,20=` 自动缩进 10-20 行，`gg=G` 全文件格式化；
- **处理大文件**：关闭高亮与折行 `:set nohlsearch nowrap` 提升性能；
- **日志排查**：`/ERROR` + `n` 快速定位，`:%s/时间戳//g` 批量清洗。
