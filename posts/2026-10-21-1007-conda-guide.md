## 一、conda 是什么？

conda 是一个开源的**软件包管理系统**和**环境管理系统**：它可以安装多个版本的软件包及其依赖，并在它们之间轻松切换。

- 在 **Windows** 下，建议通过 **Anaconda Prompt** 执行 conda 命令；
- 在 **Linux / macOS** 下，直接在终端执行即可。

conda 最核心的能力是**虚拟环境（Virtual Environment）**：每个环境拥有独立的包与其依赖，互不干扰。Anaconda 自带一个名为 `base` 的默认环境，但一般不建议把项目直接放进 base——想象你有多个项目，有的需要 `numpy` 低版本、有的需要高版本，众口难调。为每个项目创建独立环境，就能把它们彻底隔离，各用各的版本。

## 二、管理 conda 自身

```bash
# 查看 conda 版本
conda --version

# 查看 conda 环境配置
conda config --show

# 查看 conda 详细信息（配置路径、通道等）
conda info

# 更新 conda 到最新版本（官方建议始终保持在最新版）
conda update conda

# 更新整个 Anaconda
conda update Anaconda

# 查看某条命令的帮助
conda create --help
```

## 三、环境管理（核心）

### 1. 创建环境

```bash
# 创建名为 env_name、Python 版本 3.13 的环境
conda create -n env_name python=3.13

# 创建环境的同时安装若干包（简单任务推荐分开做）
conda create -n env_name numpy matplotlib python=3.13
```

- `-n` 即 `--name`，后接自定义环境名；
- `python=3.7` 会安装最新的 3.7 系列（如 3.7.12），想锁定具体版本用 `python=3.7.2`；
- 创建后可到 Anaconda 安装目录的 `envs/` 下找到该环境文件夹。

### 2. 查看 / 激活 / 退出环境

```bash
# 查看所有环境（带 * 的是当前活动环境）
conda info --envs
conda info -e
conda env list

# 激活（进入）某个环境
conda activate env_name

# 退出当前环境，回到 base
conda deactivate

# 检查当前环境的 Python 版本
python --version
```

> 4.6 之前的老写法是 Linux `source activate xxx`、Windows `activate xxx`；现在统一用 `conda activate / conda deactivate` 即可。

### 3. 删除 / 复制环境

```bash
# 删除整个环境及其所有包
conda remove -n env_name --all

# 复制环境（克隆）
conda create -n new_env --clone old_env
```

### 4. 导出与还原环境

把环境配置导出成 `environment.yml`，可以备份、恢复，也可以发给别人完整复刻你的环境：

```bash
# 导出当前环境配置到 yml 文件
conda env export > environment.yml

# 根据 yml 文件创建环境
conda env create -f environment.yml

# 指定环境名创建
conda env create -n env_name -f environment.yml
```

## 四、包管理

对包的操作建议**先激活目标环境**再执行，避免装错环境。

```bash
# 查看当前环境已安装的包
conda list

# 查看指定环境的包列表
conda list -n env_name

# 模糊查找某个包是否已安装（支持 * 通配）
conda list numpy
conda list numpy*

# 在 conda 源中搜索某个包
conda search package_name

# 安装包（支持 = 号指定版本，单等号）
conda install package_name
conda install numpy=0.20.3

# 从指定频道安装（如 conda-forge）
conda install pkg_name -c conda_forge

# 更新包 / 更新所有包
conda update package_name
conda update --all

# 移除包（注意：conda 是 remove，不是 uninstall）
conda remove package_name
```

**清理缓存**——conda 会把历史安装包都缓存下来（好处是恢复旧版本快，坏处是占空间）：

```bash
conda clean -p        # 删除无用的缓存包 --packages
conda clean -t        # 删除 tar 打包文件 --tarballs
conda clean -y --all  # 删除所有安装包及 cache（索引缓存、锁定文件等）
conda clean -h        # 查看清理命令帮助
```

> 有人用 `conda clean -y --all` 一次性清出了约 30G 空间。缓存占用过大时，也可以考虑在安装时设置 `conda config --set always_yes false`，把自动确认交还给自己。

## 五、Python 版本管理

```bash
# 把当前环境的 Python 切到指定版本
conda install python=3.5

# 升级 Python 到最新版本
conda update python

# 验证版本
python --version
```

## 六、conda install vs pip install

| 对比项 | conda | pip |
|---|---|---|
| 管理范围 | 非 Python 包也能管 | 只能管 Python 包 |
| 环境能力 | 自带虚拟环境 | 需要依赖 virtualenv 等 |
| 包来源 | 编译好的二进制文件，自动装依赖 | wheel 或源码，不处理 Python 之外的语言依赖 |
| 依赖解析 | **SAT solver**，保证环境中所有包互相满足 | 递归串行安装，顺序不当可能微妙地破坏环境 |
| 安装位置 | 统一放 `anaconda3/pkgs`，多环境复用缓存 | 直接装进对应环境的 site-packages |

**能否混用？** 官方和社区一致意见：**不建议**。混用容易让依赖关系混乱，轻则装不了新包、`conda update` 失败，重则整个环境崩溃。而且 conda 仓库的包远少于 PyPI（PyPI 约 15 万可用包，Anaconda 官方仓库约 1500 个），有些包确实只能 pip 装。

**什么时候用 pip？** 只有 `conda install` 搞不定时才用 pip，且尽量在虚拟环境内使用（先 `conda install pip`），并做好环境隔离。

如何判断某个包是 conda 装的还是 pip 装的？执行 `conda list`，**build 列为 `pypi` 的就是 pip 安装的**。

## 七、更换国内镜像源

conda 安装慢是常见痛点，换国内源后明显提速。

**清华源（Windows 直接执行）：**

```bash
conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/main/
conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/free/
conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/cloud/conda-forge/
conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/cloud/msys2/
conda config --set show_channel_urls yes
```

**中科大源：**

```bash
conda config --add channels https://mirrors.ustc.edu.cn/anaconda/pkgs/main/
conda config --add channels https://mirrors.ustc.edu.cn/anaconda/pkgs/free/
conda config --add channels https://mirrors.ustc.edu.cn/anaconda/cloud/conda-forge/
conda config --set show_channel_urls yes
```

**查看 / 恢复源：**

```bash
conda config --show channels      # 查看当前配置的源
conda config --remove channels <url>   # 移除某个源
conda config --remove-key channels     # 恢复默认源
```

> 源配置保存在 `~/.condarc`（YAML 格式），第一次运行 `conda config` 时自动创建；Linux 下也可以直接编辑该文件。

## 结语

conda 的日常使用可以浓缩成一句话：**管理好环境（create / activate / deactivate / remove），管理好包（list / install / update / remove / clean），源太慢就换镜像**。记住三点：环境隔离优先、pip 只在 conda 无能为力时使用、缓存记得定期清理，你的开发环境会稳定很多。
