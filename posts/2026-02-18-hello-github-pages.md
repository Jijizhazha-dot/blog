不想再为博客维护一套构建工具，所以把站点压成了一个 `index.html`：没有构建步骤，没有依赖树，改一行文字就是改一行文字。

## 为什么放弃静态生成器

生成器的好处是文章能用 Markdown 写、模板能复用；代价是每次升级都得跟着人家的节奏跑，主题坏了自己修不了。对我这种一年写十几篇的人，这个交换并不划算。

## 现在的工作流

1. 在 `posts/` 里新建一个 `.md` 文件
2. 上传到仓库（网页上拖进去就行）
3. 首页自动读取 `posts/` 目录，把新文章排到最前面

```bash
git push origin main
```

> 唯一需要记住的约定：文件名不要重复，日期写在 front matter 的 `date` 里。

代码高亮、评论、RSS 都还没有，需要的时候再加。
