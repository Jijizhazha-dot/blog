## 一、CMD 是什么？

**CMD（Command Prompt，命令提示符）** 是 Windows 系统自带的命令行解释器，由 `cmd.exe` 提供。它源于 MS-DOS 时代：用户通过输入文本命令，直接与操作系统交互——执行程序、管理文件、配置网络、控制系统。

相比图形界面，CMD 的优势在于：

- **效率高**：一条命令顶多次鼠标点击，支持批量操作；
- **可脚本化**：把命令写进 `.bat` 文件，双击即可自动执行；
- **资源占用少**：适合远程服务器维护、系统修复等轻量场景；
- **兜底能力**：图形界面崩溃（如资源管理器卡死）时，CMD 往往是最后的修复通道。

## 二、如何打开 CMD

| 方法 | 操作 |
|---|---|
| 最常用 | 按 **Win + R** 打开运行窗口，输入 `cmd` 回车 |
| 当前目录打开 | 在任意文件夹的地址栏输入 `cmd` 回车，打开后自动定位到该文件夹 |
| 管理员身份 | 开始菜单搜索"命令提示符"，右键选择"以管理员身份运行"（部分高权限命令必须） |
| 开始菜单 | 开始菜单 → Windows 系统 → 命令提示符 |
| 资源管理器地址栏 | 直接输入 `cmd` 回车 |

> 每条命令输入后回车运行。命令正确则回到 `>` 提示符；出错会返回错误信息。

## 三、CMD 与 PowerShell 的区别

很多新手分不清两者，记住这一句就够：

- **CMD**：Windows 全系内置（Win7 到 Win11 都原生支持），轻量、简洁、零门槛，本文所有基础命令在 CMD 中都能直接运行；
- **PowerShell**：微软后来推出的升级版终端，功能更强，主打自动化运维与权限管理；它**向下兼容 CMD**——基础 CMD 指令复制进 PowerShell 也能用，只是命令更复杂。

新手直接用 CMD 即可，完全够用。

## 四、基础操作与效率技巧（新手必记）

```bat
cls          :: 清空屏幕
exit         :: 退出终端窗口
/?           :: 查看任何命令的帮助，如 ping /?
help         :: 列出常用命令帮助
```

**效率小技巧：**

- **Tab 键**：自动补全文件名/路径，杜绝输错（连按切换候选，Shift+Tab 反向）；
- **↑ / ↓ 方向键**：调取之前输入过的命令，不用重复敲；
- **Ctrl+C**：终止当前命令（如持续 ping）；
- **Ctrl+V**：粘贴内容到窗口；
- **Ctrl+P / Ctrl+N**：上下翻历史命令。

**命令组合与重定向：**

```bat
cd D:\test & dir           :: & 无论成败都执行后一条
copy a.txt b.txt && del a.txt   :: && 前一条成功才执行后一条
ping 192.168.1.1 || echo 网络不通 :: || 前一条失败才执行后一条
systeminfo > C:\sysinfo.txt     :: > 覆盖写入文件
dir >> C:\filelist.txt          :: >> 追加写入文件
dir | find ".txt"               :: | 管道，把前命令输出交给后命令
ping 1.1.1.1 2> C:\err.log      :: 2> 把错误信息写入文件
del *.log                       :: * 通配任意字符串
del test?.txt                   :: ? 匹配单个字符
cd "D:\我的文档"                :: 含空格的路径用引号包裹
```

## 五、文件与目录操作

```bat
dir                        :: 查看当前目录下的文件与子目录
dir /s                      :: 含所有子目录；dir /a 含隐藏文件
cd D:\work                  :: 切换目录（跨盘符用 cd /d）
cd ..                       :: 返回上一级
cd \                        :: 返回当前盘根目录
D:                          :: 直接切换磁盘（记得加冒号）
tree D:\project             :: 以树形显示目录结构

md 项目文档\2024            :: 新建目录（可一次建多级）
copy a.txt D:\backup        :: 复制文件（不支持复制文件夹）
xcopy study D:\file /e /i   :: 高级复制，/e 含子目录，/i 自动识别文件夹
robocopy D:\video E:\bk /E /Z /R:3 :: 高速复制，支持断点续传
move a.txt D:\backup        :: 移动（剪切粘贴），也用于重命名
ren old.txt new.txt         :: 重命名文件/文件夹
ren *.txt 文档_*.txt        :: 批量改名

del *.tmp                   :: 删除文件（支持通配，不可恢复！）
rd 空文件夹                 :: 删除空目录
rd /s /q study              :: 强制删除非空目录（高危！无确认弹窗）

type config.txt             :: 终端直接查看文本文件内容
more 长日志.txt             :: 分页查看长文件（空格翻页，Q 退出）
fc a.txt b.txt              :: 比较两个文件差异
findstr "error" log.txt     :: 在文件内搜索关键词（支持正则）
attrib +h 秘密.txt          :: 加隐藏属性；-r 取消只读
type nul > readme.md        :: 新建空文件
echo hello > test.txt       :: 新建文件并写入内容
```

## 六、网络排查与管理

```bat
ipconfig                    :: 查看本机 IP、子网掩码、网关、DNS
ipconfig /all               :: 查看完整网卡信息（含 MAC）
ipconfig /release           :: 释放 IP
ipconfig /renew             :: 重新获取 IP
ipconfig /flushdns          :: 刷新 DNS 缓存（网页打不开时先试）

ping baidu.com              :: 测试网络连通性与延迟
ping -n 5 192.168.1.1       :: 发送 5 个包
ping -t 192.168.1.1         :: 持续 ping，Ctrl+C 停止
tracert baidu.com           :: 路由追踪，定位卡顿节点
pathping baidu.com          :: 结合 ping+tracert，显示每跳丢包率
netstat -ano                :: 查看端口占用与对应 PID（排错神器）
nslookup baidu.com          :: 查询域名解析的 IP
netsh wlan show profiles    :: 查看连接过的 WiFi 列表
netsh wlan show profile "WiFi名" key=clear :: 查看 WiFi 密码
curl -O https://xxx.com/a.exe :: Win10+ 自带，下载文件
net use Z: \\192.168.1.100\share :: 映射网络驱动器为 Z 盘
```

## 七、系统管理与进程

```bat
systeminfo                  :: 查看系统版本、硬件配置、补丁
whoami                      :: 查看当前登录用户名
tasklist                    :: 列出所有运行进程（相当于任务管理器）
tasklist /fi "IMAGENAME eq chrome.exe" :: 筛选指定进程
taskkill /f /im chrome.exe  :: 按名称强制结束进程
taskkill /f /pid 1234       :: 按 PID 结束进程

shutdown /s /t 60           :: 60 秒后关机
shutdown /r /t 0            :: 立即重启
shutdown /a                 :: 取消关机/重启计划
shutdown /l                 :: 注销当前用户
shutdown /h /f              :: 休眠

sfc /scannow                :: 系统文件检查并修复（需管理员）
chkdsk C: /f                :: 检查并修复磁盘错误（可能需重启）
sc start "wuauserv"         :: 启动服务（sc stop / sc config 同理）
net user 用户名 密码 /add   :: 新建用户
net localgroup administrators 用户名 /add :: 提权为管理员
```

## 八、系统工具快捷打开

在 CMD 或 Win+R 中输入即可一键唤起：

| 命令 | 打开内容 | 命令 | 打开内容 |
|---|---|---|---|
| `notepad` | 记事本 | `devmgmt.msc` | 设备管理器 |
| `calc` | 计算器 | `services.msc` | 服务管理器 |
| `mspaint` | 画图 | `diskmgmt.msc` | 磁盘管理 |
| `control` | 控制面板 | `eventvwr.msc` | 事件查看器 |
| `msconfig` | 系统配置 | `gpedit.msc` | 本地组策略（专业版+） |
| `regedit` | 注册表编辑器 | `sysdm.cpl` | 系统属性→高级 |
| `winver` | 系统版本 | `mmsys.cpl` | 声音设置 |
| `powercfg /list` | 电源计划 | `ncpa.cpl` | 网络连接 |

## 九、新手避坑提醒

1. **`rd /s /q` 是核弹级命令**：强制删除无确认、无法找回，千万别乱删系统文件夹；
2. **`del` 删除不可恢复**，批量删除前先确认通配符范围；
3. **`diskpart`、`regedit`、`gpedit.msc`** 影响系统核心，新手看看即可，不要随便实操；
4. **结束进程前先看清用途**，别关掉系统核心进程（如 explorer、svchost）导致电脑出问题；
5. 需要管理员权限的命令（`sfc`、`chkdsk`、`netsh` 部分功能），记得**以管理员身份打开** CMD；
6. 路径含中文或空格时，直接输入或用引号包裹即可，不用额外加转义。

## 结语

CMD 并不难：**输入一条命令 + 回车**，知道它有什么用、什么时候用就行。日常文件管理用 `dir / cd / copy / del`，网络排错用 `ipconfig / ping / netstat`，系统维护用 `tasklist / shutdown / sfc`，遇到图形界面搞不定的场景，它就是最后的兜底工具。把常用的几条存成 `.bat` 脚本，效率还能再上一层。
