# Windows CMD 常用命令：入门、文件操作与网络排查

![CMD 教程封面（原文标注为 AI 生成插画）](images/2026-10-21-cmd-guide-02.jpg)

CMD 是 Windows 自带的命令行解释器，由 `cmd.exe` 提供。它适合文件操作、运行程序、查询系统和网络排查，也可以通过 `.bat` 文件重复执行任务。

本文以 Windows 10/11 为主要环境。部分命令和图形工具的可用性取决于系统版本、版本类型及已安装组件。

## 使用前先看

- 以下命令在 **CMD** 中执行。
- Windows Terminal 可以打开 CMD，也可以打开 PowerShell；请确认当前标签页使用的是命令提示符。
- 普通文件练习不需要管理员权限；系统修复、服务管理等操作会单独说明。
- 表格中的命令按需执行，不需要整篇连续运行。
- 本文经过文字和语法层面的审阅，未实机测试。
- 图片路径沿用原文，发布前请确认对应文件存在。

## 一、打开 CMD 与查询帮助

### 打开方式

| 场景 | 操作 |
|---|---|
| 普通打开 | 按 `Win + R`，输入 `cmd`，回车 |
| 从当前文件夹打开 | 在文件资源管理器地址栏输入 `cmd` |
| 管理员打开 | 开始菜单搜索"命令提示符"，选择"以管理员身份运行" |
| Windows Terminal | 从配置菜单中打开"命令提示符"标签页 |

从本地文件夹地址栏打开时，通常会定位到该目录。网络共享路径可使用后文的 `pushd`。

### 查看帮助

```bat
help
```

查看具体命令：

```bat
dir /?
copy /?
help cd
```

`/?` 通常要跟在具体命令之后，不能把它当作独立的通用帮助命令。

### 常用操作

| 操作 | 方法 |
|---|---|
| 清屏 | `cls` |
| 退出当前 CMD | `exit` |
| 调取历史命令 | 上、下方向键 |
| 补全路径或文件名 | `Tab` |
| 尝试中断当前程序 | `Ctrl+C` |
| 粘贴 | 常见环境支持 `Ctrl+V`，具体取决于终端设置 |

命令执行后回到提示符，并不代表成功。应结合输出、错误提示和该命令的返回码规则判断。

## 二、CMD、PowerShell 与终端的区别

CMD 和 PowerShell 是不同的 Shell；Windows Terminal 是承载它们的终端应用。

两者可以运行许多相同的外部程序，例如 `ping.exe`。但内置命令、变量、引号和脚本语法并不完全兼容。

例如：

- CMD 使用 `%TEMP%` 访问环境变量。
- PowerShell 使用 `$env:TEMP`。
- CMD 的 `dir` 是内置命令；PowerShell 中的 `dir` 通常是 `Get-ChildItem` 的别名。

本文的代码应在 CMD 中执行。

## 三、先完成一次文件操作练习

下面会在临时目录下创建练习文件夹。如果该名称已经存在，会提示停止；此时先更换名称，再重新执行。

代码包含写文件操作，请完整阅读后复制到 CMD。

```bat
set "CMD_DEMO_DIR=%TEMP%\cmd-demo-%RANDOM%-%RANDOM%"
if exist "%CMD_DEMO_DIR%" (echo Directory exists. Choose another name.) else (mkdir "%CMD_DEMO_DIR%" && cd /d "%CMD_DEMO_DIR%")
```

确认当前路径已经切换到新建目录，再继续：

```bat
mkdir "backup"
echo Hello, CMD!> "file.txt"
echo INFO service started> "app.log"
echo ERROR connection failed>> "app.log"
copy /-Y "file.txt" "backup\file.txt"
ren "backup\file.txt" "copied.txt"
dir
type "file.txt"
findstr /n /i /l /c:"error" "app.log"
echo Practice directory: "%CD%"
```

预期结果：

- 当前目录有 `file.txt`、`app.log` 和 `backup` 文件夹。
- `backup` 中有 `copied.txt`。
- 搜索命令显示日志中包含 `error` 的行，并附带行号。

后文使用这些文件的例子，需要在该练习目录中执行。

## 四、目录切换与文件查看

| 目的 | 命令 | 说明 |
|---|---|---|
| 查看当前路径 | `cd` | 不带参数时显示路径 |
| 列出目录内容 | `dir` | 显示当前目录 |
| 包含隐藏项目 | `dir /a` | 显示各种属性的项目 |
| 包含子目录 | `dir /s` | 大目录可能输出很多内容 |
| 只显示名称 | `dir /b` | 便于生成文件列表 |
| 返回上一级 | `cd ..` | |
| 返回当前盘根目录 | `cd \` | |
| 跨盘切换目录 | `cd /d "D:\work"` | 路径必须实际存在 |
| 切换盘符 | `D:` | 切换到 D 盘记录的当前目录 |
| 显示目录树 | `tree /f` | `/f` 同时列出文件 |
| 查看文本 | `type "file.txt"` | 适合较短文本 |
| 分页查看 | `more "app.log"` | 空格翻页，通常按 `Q` 退出 |

### 网络共享路径

将下面的服务器和共享名替换为实际值：

```bat
pushd "\\server\share"
```

`pushd` 可以临时为 UNC 共享路径分配盘符。完成后返回：

```bat
popd
```

### 路径中的空格与特殊字符

路径建议始终加双引号：

```bat
cd /d "D:\My Documents"
```

中文本身通常不要求额外转义，但显示和文本读写仍可能受编码影响。

`&`、`|`、`<`、`>`、`%` 等字符具有语法含义。双引号不能在所有场景下取消变量展开等行为，复杂路径和批处理应单独核对。

## 五、创建、复制、移动与删除

### 创建目录与文件

创建多级目录：

```bat
mkdir "notes\2026"
```

写入或覆盖文本文件：

```bat
echo Hello, CMD!> "message.txt"
```

追加一行：

```bat
echo Another line>> "message.txt"
```

创建空文件：

```bat
type nul > "empty.txt"
```

如果目标文件已经存在，`type nul >` 会清空它。`>` 不是"仅在文件不存在时创建"。

### 复制文件

以下例子使用练习目录：

```bat
copy /-Y "file.txt" "backup\file.txt"
```

`/-Y` 在覆盖已有目标文件前询问。`copy` 不用于递归复制整个目录。

### 复制目录

将源、目标路径替换为实际目录，目标应位于源目录之外：

```bat
robocopy "D:\project" "E:\backup\project" /E /Z /R:3 /W:5
```

| 参数 | 含义 |
|---|---|
| `/E` | 包含所有子目录，包括空目录 |
| `/Z` | 使用可重启复制模式 |
| `/R:3` | 失败后最多重试 3 次 |
| `/W:5` | 每次重试等待 5 秒 |

这不是镜像同步，不会因为源目录缺少某个文件就自动删除目标中的对应文件。

Robocopy 返回码 `0～7` 通常不表示复制失败，`8` 及以上表示至少存在一项失败。不能直接用一般命令的返回码习惯解释它。

旧工具 `xcopy` 也可以复制目录：

```bat
xcopy "D:\project" "E:\backup\project" /E /I /-Y
```

这是另一种选择，不需要和 Robocopy 连续执行。

### 移动与重命名

将文件移入已有目录：

```bat
move /-Y "message.txt" "backup\"
```

重命名：

```bat
ren "empty.txt" "renamed.txt"
```

批量修改扩展名：

```bat
ren "*.log" "*.bak"
```

执行批量重命名前先列出匹配文件。CMD 的 `ren` 通配符映射不适合作为通用的"给所有文件添加前缀"方法。

### 删除前先确认范围

先查看要匹配的文件：

```bat
dir /b /a:-d "*.tmp"
```

确认后逐项询问删除：

```bat
del /p "*.tmp"
```

删除空目录：

```bat
rd "notes\2026"
```

删除目录及其内容，并保留确认：

```bat
rd /s "backup"
```

`rd /s /q` 会取消确认，不建议作为默认练习。

`del` 和 `rd` 通常不经过桌面回收站。是否能恢复取决于存储介质、后续写入和备份，不能把恢复当作可靠的撤销方式。

### 文件比较与属性

比较两个文件：

```bat
fc "file.txt" "backup\copied.txt"
```

查看属性：

```bat
attrib "file.txt"
```

添加隐藏属性：

```bat
attrib +h "file.txt"
```

取消隐藏属性：

```bat
attrib -h "file.txt"
```

隐藏属性不是访问权限控制，不能用于保护敏感文件。

## 六、命令组合、管道与重定向

| 符号 | 含义 | 示例 |
|---|---|---|
| `&` | 顺序执行，不要求前一条成功 | `echo First & echo Second` |
| `&&` | 前一条报告成功才执行后一条 | `mkdir "new-dir" && echo Created` |
| `\|\|` | 前一条报告失败才执行后一条 | `dir "missing.txt" \|\| echo Not found` |
| `\|` | 将标准输出交给下一个命令 | `tasklist \| findstr /i "notepad.exe"` |
| `>` | 标准输出写入文件，覆盖原内容 | `dir /b > "files.txt"` |
| `>>` | 标准输出追加到文件 | `echo Finished>> "run.log"` |
| `2>` | 标准错误写入文件 | `dir "missing.txt" 2> "errors.txt"` |
| `2>&1` | 将标准错误并入当前标准输出目标 | `dir "missing.txt" > "result.txt" 2>&1` |

`2>&1` 的顺序有意义。上例先指定标准输出文件，再把标准错误并入该目标。

不同程序不一定把所有错误文字都写入标准错误。例如，不能假设 `ping` 的所有失败信息都能通过 `2>` 捕获。

查看上一条命令的返回码，通常可以在它之后单独输入：

```bat
echo %ERRORLEVEL%
```

返回码的含义应查阅具体命令说明。括号代码块中的变量展开还有额外规则，不能机械照搬此写法。

### 搜索文本

在练习日志中搜索：

```bat
findstr /n /i /l /c:"error" "app.log"
```

- `/n`：显示行号。
- `/i`：忽略大小写。
- `/l`：按字面文本匹配。
- `/c:`：将引号内内容作为一个搜索字符串。

`findstr` 支持有限的正则语法，不能直接套用所有常见正则表达式。

涉及中文、UTF-8、UTF-16 或复杂文本处理时，应核对工具对编码的支持；必要时使用 PowerShell 等更适合文本处理的工具。

## 七、网络查询与排查

### 先使用查询命令

| 目的 | 命令 |
|---|---|
| 查看基本网络配置 | `ipconfig` |
| 查看网卡、DNS 等详细信息 | `ipconfig /all` |
| 测试域名的 ICMP 连通性 | `ping -n 4 example.com` |
| 追踪路由 | `tracert example.com` |
| 进行较长时间的路径统计 | `pathping example.com` |
| 查询 DNS | `nslookup example.com` |
| 查看连接、监听端口和 PID | `netstat -ano` |
| 查看已保存的无线配置 | `netsh wlan show profiles` |

说明：

- `ping` 不通不等于网站不可访问，目标可能不响应 ICMP。
- `tracert` 中出现 `*`，可能是设备不响应探测，不能直接认定该跳故障。
- `pathping` 可能需要较长时间，结果也受设备响应策略影响。

### 查找 8080 相关条目

```bat
netstat -ano | findstr /c:":8080"
```

这只是文本筛选，可能匹配远端端口或其他包含该字符串的内容。需要同时查看本地地址、状态和最后一列 PID。

再按实际 PID 查询进程，例如：

```bat
tasklist /fi "PID eq 1234"
```

`1234` 必须替换为查询到的进程 ID。

### 刷新 DNS 缓存

通常在管理员 CMD 中执行：

```bat
ipconfig /flushdns
```

它只清理本机 DNS 解析缓存，不能保证解决所有网页访问问题。

### 释放与重新获取 DHCP 地址

以下操作可能中断当前网络连接，远程会话中尤其需要注意。它们主要针对使用 DHCP 的适配器。

```bat
ipconfig /release
```

需要重新获取时：

```bat
ipconfig /renew
```

不应把这两条命令当作所有网络故障的默认处理步骤。

### 下载网页

先确认 `curl` 是否可用：

```bat
where curl
```

较新的 Windows 通常提供 `curl.exe`，旧版本或精简环境可能没有。

将网页保存到当前目录：

```bat
curl --fail --location --output "example.html" "https://example.com/"
```

同名输出文件可能被覆盖。下载成功只说明请求和保存完成，不代表下载内容已经过可信性验证。

### 映射网络共享

将服务器、共享名和盘符替换为实际值，并确认 `Z:` 尚未使用：

```bat
net use Z: "\\server\share" /persistent:no
```

取消映射：

```bat
net use Z: /delete
```

访问需要相应的网络连通性和共享权限。

## 八、系统信息、进程与维护

### 查看信息

```bat
systeminfo
whoami
tasklist
```

筛选记事本进程：

```bat
tasklist /fi "IMAGENAME eq notepad.exe"
```

### 结束进程

先查询并确认 PID，再尝试普通终止：

```bat
taskkill /pid 1234
```

只有在确认目标且普通终止无效时，再考虑：

```bat
taskkill /f /pid 1234
```

`/f` 表示强制终止，可能丢失未保存数据。按名称终止可能影响多个同名进程。

### 关机与重启

以下命令会影响当前会话和正在运行的程序，应按需分别执行。

安排 60 秒后关机：

```bat
shutdown /s /t 60
```

超时时间大于 0 时，Windows 会隐含强制关闭程序的行为，应先保存工作。

在有效倒计时内取消：

```bat
shutdown /a
```

立即重启：

```bat
shutdown /r /t 0
```

注销当前用户：

```bat
shutdown /l
```

休眠：

```bat
shutdown /h
```

休眠需要系统支持并已启用。`shutdown /a` 不能撤销已经开始执行的关机或注销过程。

### 系统文件检查

在管理员 CMD 中执行：

```bat
sfc /scannow
```

它会检查并尝试修复受保护的 Windows 系统文件，可能耗时较长。

### 磁盘检查

检查卷并报告状态：

```bat
chkdsk C:
```

尝试修复文件系统错误：

```bat
chkdsk C: /f
```

修复通常需要管理员权限和卷锁定；系统卷可能提示安排到下次重启时执行。重要数据应先备份，修复命令不能代替硬盘健康检查或备份。

### 服务查询与控制

查询 Windows Update 服务：

```bat
sc query wuauserv
```

启动服务通常需要管理员权限：

```bat
sc start wuauserv
```

`sc stop`、`sc config` 各自有参数和适用条件，不能简单替换子命令后照抄。修改前查看：

```bat
sc config /?
```

### 创建本地用户

以下操作通常需要管理员权限。`cmd-demo` 是账户名称示例，可按需替换。

```bat
net user "cmd-demo" * /add
```

`*` 让系统提示输入密码，避免直接把明文密码写入命令。

添加到管理员组属于另一个权限操作，不是创建用户的必需步骤。管理员组名称还可能随系统语言变化，操作前应确认实际组名和授权范围。

## 十、将命令保存为批处理

下面的脚本在自身所在目录生成 `files.txt`，列出该目录中的文件名。同名输出文件会被覆盖。

保存为 `list-files.bat`：

```bat
@echo off
setlocal
REM Switch to the directory containing this script.
pushd "%~dp0" || exit /b 1
REM Exclude the output file from its own listing.
dir /b /a:-d | findstr /v /x /i /l /c:"files.txt" > "files.txt"
echo Output: "%CD%\files.txt"
popd
endlocal
pause
```

注意：

- 保存时确认文件实际扩展名为 `.bat`，不是 `.bat.txt`。
- 注释使用独立的 `REM` 行。
- `%~dp0` 表示批处理文件所在的驱动器和目录。
- 脚本编码、控制台代码页和外部程序编码需要配合；中文显示异常时，应先确认原因，不必默认永久更改代码页。
- 如果以后使用 `for`：交互式 CMD 常用 `%F`，批处理文件中使用 `%%F`。
